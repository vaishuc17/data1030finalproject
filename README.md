# Predicting Diabetes Status Using Health Factors

## Overview
This project is aimed at using different machine learning models to classify an individual as not having diabetes, having prediabetes, or having diabetes by using different health and demographic featues. The dataset used for this project can be found [here](https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset?select=diabetes_012_health_indicators_BRFSS2015.csv) or by navigating to the 'data' directory. The paper describing the EDA, methods, and results is available for viewing within the 'report' directory.
